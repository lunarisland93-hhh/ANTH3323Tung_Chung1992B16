## 目錄結構

```
tung-chung-1992/
├── index.html              ← 入口頁（含開箱動畫、三欄佈局）
├── css/base.css            ← 所有樣式
├── js/app.js               ← 地圖與互動邏輯
├── data/
│   └── photos.json         ← 36 筆照片資料（勿手改）
└── assets/
    ├── photos/              ← B16P01.jpg – B16P36.jpg
    ├── icons/               ← S01.png – S07.png（建築膠帶 icon）
    └── maps/                ← 1982 地形圖（4 張 TIF 已拼接）
        └── tung-chung-1982-stitch.jpg
```

---

## ⚠️ 不可動的部分

以下已驗證正確，修改會導致對位或資料出錯：

1. **`js/app.js` 中的 `TILES_1982` bounds**——4 張地形圖的 WGS84 座標範圍，由 pyproj 從原始 TIF 的 .tfw world file 精算。改了就對不準。
2. **`data/photos.json`**——從使用者人工校對的 xlsx 生成，36 筆照片的座標、站名、精度欄位均已人工確認。
3. **`assets/maps/map-1982-*.jpg`**——由原始 TIF 降解析度而來，georeferencing 正確。

## 設計規範

配色（已寫在 CSS `:root`）：
- 奶油白 `#F5F0E6`：主要背景
- 墨黑褐 `#38332E`：正文
- 牛皮紙棕 `#C6A57B`：紙箱、資料夾
- 苔蘚綠 `#71816B`：地圖標記、選取
- 褪色藍 `#718C9C`：點綴

風格：田野筆記 × 牛皮紙資料夾 × 簡單照片拼貼。不要遊戲 UI、不要繁複裝飾。

字體：宋體/明體標題 + 黑體正文。

完整設計需求見：`../《開箱東涌・1992》互動照片檔案與故事地圖製作方案 (1).md`
